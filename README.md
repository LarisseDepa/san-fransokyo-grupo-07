## Sobre o projeto

O CLARO GUIA é uma solução acadêmica que simula o consumo de internet dos usuários, identifica mudanças nos padrões de utilização e apresenta recomendações de planos de acordo com o perfil simulado.

A proposta é demonstrar como a análise de dados pode contribuir para compreender o comportamento de consumo e apoiar a tomada de decisão.

## Problema identificado

O consumo de internet varia de acordo com os hábitos de cada usuário. Quando esse consumo aumenta, o plano contratado pode deixar de atender às suas necessidades.

O projeto demonstra como a análise de dados pode ajudar a identificar essas mudanças e apoiar a escolha de planos mais adequados.

## Solução proposta

O CLARO GUIA utiliza dados simulados e modelos de Machine Learning para:

- Analisar padrões de consumo.
- Estimar a demanda de internet.
- Identificar possíveis mudanças de utilização.
- Recomendar planos de acordo com o perfil simulado.

## Tecnologias e métodos utilizados

| Tecnologia ou método | Aplicação no projeto |
|---|---|
| Python | Desenvolvimento e análise de dados |
| Pandas | Tratamento e manipulação dos dados |
| Random Forest | Estimativa da demanda de internet |
| Filtragem colaborativa | Identificação de similaridades entre perfis |
| Correlação de Pearson | Cálculo de similaridade entre usuários |
| Sistema híbrido | Combinação de técnicas de recomendação |
| Marimo | Desenvolvimento de notebook interativo |
| Pixi | Gerenciamento do ambiente e dependências |

## Modelagem e resultados

O projeto utiliza diferentes técnicas para estimar o consumo e gerar recomendações:

- **Random Forest:** utilizado para estimar a demanda de internet.
- **Filtragem colaborativa:** identifica similaridades entre perfis de usuários.
- **Correlação de Pearson:** auxilia no cálculo da similaridade entre usuários.
- **Recomendador híbrido:** combina Random Forest e filtragem colaborativa.

Os modelos são avaliados em um ambiente de simulação com dados fictícios.

## Como executar o projeto

### 1. Instalação do Pixi

**Windows (PowerShell):**

```powershell
powershell -ExecutionPolicy Bypass -c "irm -useb https://pixi.sh/install.ps1 | iex"
```

**macOS/Linux:**

```bash
curl -fsSL https://pixi.sh/install.sh | sh
```

### 2. Instalação das dependências

Na pasta do projeto, abra o terminal e execute:

```bash
pixi install
```

### 3. Executar o site localmente

```bash
pixi run ver-site
```

Depois, acesse no navegador:

http://localhost:8000

Para encerrar a execução, pressione `Ctrl + C` no terminal.

### 4. Outros comandos disponíveis

| Comando | Finalidade |
|---|---|
| `pixi run editar` | Editar e executar o notebook Marimo |
| `pixi run site` | Gerar o site estático |
| `pixi run testes` | Executar os testes após gerar o site |

## Publicação do projeto

O projeto utiliza GitHub Actions para gerar e publicar o site automaticamente. Novos envios para a branch principal repetem o processo de publicação e execução dos testes.

## Observação importante

Este é um projeto acadêmico de simulação.

Os dados, planos e históricos de ofertas utilizados são fictícios e não representam clientes reais, contratos ou sistemas internos da Claro.

As métricas apresentadas avaliam o funcionamento dos modelos dentro do ambiente simulado.
